## Hi, I'm Kacper

Doctoral researcher at the [Alfred Wegener Institute](https://www.awi.de/en/) (Climate Dynamics, Bremerhaven), working on **machine learning for ocean and climate modelling**. I build ML emulators that work directly on the unstructured meshes used by modern ocean models, so the irregular coastlines and variable resolution stay intact instead of being forced onto a lat-lon grid.

### What I'm working on

- **HClimRep-Ocean**: a global ocean emulator running on the native unstructured mesh of [FESOM2](https://github.com/FESOM/fesom2), trained on a 209-year AWI-CM3 control simulation. Preprint: [arXiv:2609.28601](https://arxiv.org/abs/2609.28601)
- **[WeatherGenerator](https://github.com/ecmwf/WeatherGenerator)**: contributing to the development of ECMWF's WeatherGenerator.
- **[implicit_filter](https://github.com/FESOM/implicit_filter)**: Python package for spatial filtering and spectra extraction on unstructured meshes ([GMD paper](https://doi.org/10.5194/gmd-18-6541-2025))

### Tools I use

Python · PyTorch · JAX · NumPy · Dask · C++ · Julia · HPC (Jülich Supercomputing Centre)

### Background

Physics (BSc, MSc, University of Warsaw) and Applied Computer Science (MSc, Bydgoszcz University of Science and Technology). Before oceans I worked on top-quark physics at CLIC, optimising threshold scans with genetic algorithms ([JHEP 2021](https://doi.org/10.1007/JHEP07(2021)070)).
